# Workshop: grouping keywords by intent

THEORETICAL RECAP Search intent is the underlying goal a user has when typing a query into a search engine. Grouping keywords by intent means organizing a raw keyword list into coherent clusters based on what the user actually wants, not just on surface-level word similarity. The four classic intent categories are: informational (the user wants to learn something, e.g. 'how to do SEO'), navigational (the user looks for a specific brand or site, e.g. 'Ubersuggest login'), commercial investigation (the user compares options before buying, e.g. 'best SEO tools 2024'), and transactional (the user is ready to act or purchase, e.g. 'buy SEO software'). A useful mental model: each cluster becomes a candidate for a single page or content type, because Google ranks pages that match one dominant intent. A common mistake is to group keywords purely by shared words while ignoring intent, which leads to targeting the same page for queries that require completely different content. Another frequent error is confusing commercial investigation with transactional intent, diluting the conversion focus. Mini example: from the list 'keyword research', 'what is keyword research', 'ubersuggest', 'best keyword tool', 'buy keyword tool license', you would create four clusters: informational ('keyword research', 'what is keyword research'), navigational ('ubersuggest'), commercial investigation ('best keyword tool'), and transactional ('buy keyword tool license'). Each cluster maps to a distinct page and content angle.
