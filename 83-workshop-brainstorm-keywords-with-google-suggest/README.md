# Workshop: brainstorm keywords with Google Suggest

THEORETICAL RECAP Keyword research is the process of identifying the actual words and phrases people type into search engines. A keyword is not just a single word; it is a query that reveals a user's intent. Search intent typically falls into four categories: informational (the user wants to learn something), navigational (the user looks for a specific site), commercial (the user compares options before buying), and transactional (the user is ready to act or purchase). Your job as an SEO is to match content to these intents. Google Suggest (the autocomplete dropdown that appears as you type in the search bar) is a free, powerful brainstorming tool. When you start typing a query, Google displays the most common completions based on real searches. This exposes the vocabulary your audience actually uses, including long-tail keywords (longer, more specific, lower-competition phrases such as 'best running shoes for flat feet' instead of just 'running shoes'). The most common mistakes: focusing only on high-volume 'head' keywords that are too competitive, ignoring search intent (targeting a transactional page with informational keywords), and inventing keywords from your own vocabulary instead of observing what users type. Mini example: type 'coffee machine' into Google. Suggestions like 'coffee machine for office', 'coffee machine with grinder', 'coffee machine cleaning' each reveal a distinct intent and a content opportunity.
