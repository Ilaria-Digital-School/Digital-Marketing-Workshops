# Final mini-project: complete implementation of the environment on a personal project

## Overview This final mini-project is the capstone of the 'INTRO - First steps in digital marketing and setting up the work environment' chapter. It asks you to bring together every tool, method, and concept covered so far — persona definition, value proposition, monitoring setup, KPI tracking, Pomodoro-based organization, Trello project management, and email campaign planning — and apply them coherently to a single, real personal project of your choice. The project can be a freelance service you want to launch, a side business, a personal brand, a community initiative, or any other project where digital marketing is relevant. The key requirement is that it must be real and actionable, not hypothetical. ## What This Project Validates This mini-project is a skills validation checkpoint. It confirms that you can: - Define a target audience and articulate a clear value proposition - Set up a functional digital monitoring environment - Organize your work using proven productivity methods - Design and plan a basic email campaign - Connect all these elements into a coherent digital marketing environment ready for execution ## Pedagogical Positioning Building on your recent work — including setting up Google Alerts and Feedly, planning Trello + Pomodoro sessions, designing an email campaign plan, and integrating everything into Trello and Drive — this project asks you to stop working in isolated exercises and start working as a practitioner. Every deliverable here mirrors a real professional output.
