# Workshop: defining indicators for an existing CJM

**Theoretical Recap** A Customer Journey Map (CJM) is only as actionable as the metrics attached to it. Without indicators, a CJM remains a descriptive artifact — useful for alignment, but powerless for optimization. KPIs (Key Performance Indicators) transform each stage of the journey into a measurable reality: they tell you not just what the customer does, but whether they do it well enough to move forward. Each stage of the journey — Awareness, Consideration, Decision, Retention, Advocacy — calls for a distinct category of metrics. Awareness metrics capture reach and discovery (impressions, organic traffic, brand search volume). Consideration metrics reflect engagement (time on site, pages per session, email open rates). Decision metrics track conversion (conversion rate, cart abandonment rate, cost per acquisition). Retention metrics measure loyalty (churn rate, repeat purchase rate, NPS). Advocacy metrics capture referral behavior (referral traffic, review volume, Net Promoter Score). A common mistake is selecting vanity metrics — numbers that look good but don't inform decisions. Another is applying the same KPIs to every stage, ignoring the specific intent and emotional state of the customer at each touchpoint. Always ask: does this metric tell me whether the customer is progressing toward the next stage?
