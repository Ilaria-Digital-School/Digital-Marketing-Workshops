# Workshop: structuring an article with H1-H3

THEORETICAL RECAP Heading tags (H1 to H6) define the hierarchical structure of a web page. The H1 is the main title of the page: there must be exactly one, and it should contain the primary keyword while clearly announcing the topic. H2 tags divide the article into main sections, and H3 tags break those sections into sub-points. Think of this hierarchy as an outline or a nested table of contents: H1 is the book title, H2 are the chapters, H3 are the sub-sections within each chapter. Search engines use this structure to understand the topic, its subtopics, and their relative importance; users use it to scan and navigate quickly. Common mistakes: using multiple H1 tags, skipping levels (jumping from H1 straight to H3), using heading tags purely for visual styling instead of semantic meaning, stuffing keywords into every heading, or writing vague headings like "Introduction" that carry no search value. Good headings are descriptive, keyword-aware, and readable. Mini example for the query "how to brew cold brew coffee": H1: How to Make Cold Brew Coffee at Home H2: What You Need to Make Cold Brew H3: Choosing the Right Coffee Beans H3: Equipment and Ratios H2: Step-by-Step Cold Brew Method H3: Grinding and Steeping H3: Filtering and Storing This structure signals topic coverage, satisfies user intent, and maps naturally to the keyword brief you learned to build earlier.
