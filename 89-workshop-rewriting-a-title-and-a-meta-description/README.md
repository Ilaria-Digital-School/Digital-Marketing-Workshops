# Workshop: rewriting a Title and a Meta Description

THEORETICAL RECAP The Title tag (or 'title') is the clickable headline displayed in search engine results (SERP) and in the browser tab. It is one of the strongest on-page ranking signals and the first thing a user reads. The Meta Description is the short summary text shown below the Title in the SERP. It does not directly influence ranking, but it heavily impacts the click-through rate (CTR): a compelling description convinces users to click. A useful mental model: think of the Title + Meta Description as a mini-advertisement for your page. The Title captures attention and signals relevance to both the algorithm and the reader; the Meta Description sells the click by promising value and answering the user's intent. Key rules to remember: keep the Title between roughly 50 and 60 characters (or under ~580 pixels) to avoid truncation; place the primary keyword near the beginning; make each Title unique. For the Meta Description, aim for ~140 to 160 characters, include the keyword naturally, address the search intent, and add a clear call to action. Common mistakes: keyword stuffing, duplicate Titles across pages, descriptions that are too vague or too long, ignoring search intent, and forgetting the brand name where relevant. Mini example — Poor: 'Home | Best cheap shoes buy shoes online shoes shop'. Better: 'Running Shoes for Women | Free Shipping & 30-Day Returns' with a description that states the offer and invites the click.
