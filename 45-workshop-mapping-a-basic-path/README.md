# Workshop: mapping a basic path

THEORETICAL RECAP A Customer Journey Map (CJM) is a visual representation of the steps a user goes through when interacting with a brand, product, or service — from the very first point of awareness all the way to post-purchase behavior. At its core, it answers one question: what does the user think, feel, and do at each stage of their experience? The key components of any basic journey map include: the persona (who is experiencing the journey), the stages (the chronological phases such as Awareness, Consideration, Decision, Retention, and Advocacy), the touchpoints (every interaction between the user and the brand), the user's emotions and pain points at each stage, and the opportunities for improvement that the brand can act on. A common mental model is to think of the journey as a story told from the user's point of view, not the brand's. The most frequent mistake beginners make is mapping the journey from the company's internal process perspective rather than centering it on the user's actual lived experience. Another common error is being too vague about emotions or skipping the pain points entirely, which makes the map decorative rather than actionable. Mini example: a persona named Sophie, 34, wants to subscribe to a meal-kit delivery service.
