# Workshop: building a prioritization matrix

THEORETICAL RECAP A prioritization matrix is a decision-making tool that helps you rank keywords (or SEO actions) by comparing them across two or more weighted criteria. The most common model plots keywords on two axes: business value (potential to generate conversions or revenue) versus effort/difficulty (competition, content required, technical constraints). This produces four quadrants: high value / low effort (your "quick wins", to attack first), high value / high effort (strategic bets, to plan over time), low value / low effort (fillers, to do when convenient), and low value / high effort (to abandon). The mental model to keep in mind: you are not asking "is this keyword good?" but "is this keyword worth my time right now compared to all the others?". Common mistakes: ranking keywords only by search volume (a high-volume term you can never rank for is worthless), ignoring search intent (a keyword with commercial intent is worth more than an informational one for a sales-driven site), and using vague scoring that cannot be compared. Always score on a consistent numeric scale. Mini example: the keyword "buy running shoes online" has volume 5,000, difficulty 65, strong transactional intent. The keyword "how to lace running shoes" has volume 8,000, difficulty 12, informational intent. For an e-commerce store, the first is a strategic bet (high value, high effort), the second is a quick win to capture traffic and build authority.
