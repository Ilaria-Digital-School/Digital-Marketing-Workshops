# Workshop: identifying the key elements of a SERP

THEORETICAL RECAP SERP stands for Search Engine Results Page: the page a search engine displays in response to a query. After crawling and indexing (which you studied in the previous chapter), the engine ranks and presents results. A modern SERP is no longer a simple list of ten blue links. It is a modular page composed of distinct blocks. The main ones are: the organic results (free, earned through SEO), the paid ads (labeled 'Sponsored' or 'Ad', usually at the top and bottom), and the SERP features, which are enriched blocks such as the featured snippet (a boxed answer at position zero), the People Also Ask box, the Knowledge Panel (often on the right), Image and Video packs, the Local Pack (a map with business listings), Top Stories, and Related Searches. A useful mental model: think of the SERP as a magazine layout that the engine assembles dynamically based on search intent. A transactional query ('buy running shoes') triggers ads and shopping blocks; an informational query ('how does crawling work') triggers featured snippets and People Also Ask. Common mistakes: confusing paid ads with organic results (ads are labeled but visually similar), ignoring SERP features that steal clicks from position 1, and assuming the same query gives everyone the identical SERP (location, language, and personalization change results). Mini example: for the query 'weather Paris', Google shows a weather widget at the top, pushing organic links far down. The organic click-through rate collapses because the answer is given directly on the page....
