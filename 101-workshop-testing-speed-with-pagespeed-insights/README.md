# Workshop: testing speed with PageSpeed Insights

THEORETICAL RECAP Google PageSpeed Insights (PSI) is a free tool that evaluates the loading performance of a web page on both mobile and desktop, then returns a score from 0 to 100 along with actionable recommendations. The key concept behind it is the Core Web Vitals, three metrics that measure real user experience: LCP (Largest Contentful Paint) measures loading speed (aim for under 2.5s), INP (Interaction to Next Paint) measures responsiveness (aim for under 200ms), and CLS (Cumulative Layout Shift) measures visual stability (aim for under 0.1). The correct mental model: PSI gives you two datasets. "Field Data" reflects the real experience of actual visitors over the last 28 days, while "Lab Data" is a simulated test run in a controlled environment. Both matter, but field data is what Google uses for ranking. Common mistakes: focusing only on the overall score instead of the individual metrics; ignoring the mobile results (mobile-first indexing means mobile is what counts); and confusing lab and field data. A mini example: a page scores 90 in lab data but shows a poor LCP in field data because real users are on slower connections. This tells you your simulated test was too optimistic and the real problem lies in server response or heavy images. WORKSHOP BRIEF Your objective in this workshop is to conduct a real performance audit of a live website using PageSpeed Insights, interpret the results correctly, and produce a prioritized list of optimization actions.
